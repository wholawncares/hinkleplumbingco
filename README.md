# Hinkle Plumbing Company

Website for Hinkle Plumbing Company, Belleville, Illinois. Static HTML, no redesign of the supplied template.

## Files included

- 44 pages in the root folder
- `blog/` - 16 pages
- `assets/` - stylesheet, scripts, fonts and images
- `.htaccess`, `_redirects`, `netlify.toml`, `robots.txt`, `sitemap.xml`, `vercel.json`

## Setup

1. Upload the CONTENTS of this folder to your web host (not the folder itself)
2. Keep the files in the site's root directory
3. **Shared/cPanel hosting:** make sure `.htaccess` uploaded too. It starts with a dot, so file managers hide it by default — turn on "show hidden files" and confirm it sits next to `index.html`. Without it every page except the homepage returns 404.
4. Open the site and check the pages, links and contact details
